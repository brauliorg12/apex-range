Política de Privacidad

Apex Range es una aplicación desarrollada por CubaNova (cubanovainfo@gmail.com).

Esta aplicación no recopila, almacena ni comparte datos personales sensibles de los usuarios. Solo se procesan los datos necesarios para el funcionamiento del bot en Discord (por ejemplo, nombre de usuario, ID de Discord, roles y comandos ejecutados).

Uso de APIs Externas

El bot utiliza APIs de terceros, como la API de Mozambique y Apex Legends Status, para obtener información pública sobre Apex Legends. El bot no almacena ni comparte información personal obtenida de estas APIs.

Propiedad y Contacto

El bot es propiedad de CubaNova. Para cualquier consulta sobre privacidad, puedes contactar a cubanovainfo@gmail.com.

Actualizaciones

Esta política puede actualizarse en cualquier momento. Se recomienda revisarla periódicamente.
